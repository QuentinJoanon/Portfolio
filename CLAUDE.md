### 2. Objectively (anciennement "Take On A Decision")
- **URL** : https://objectively.fr
- **Type** : SaaS avec client référencé (Le Cèdre — centrale d'achats de 12 000 organisations)
- **Repo** : `C:\Users\Quentin\Documents\Projets\Take_On_A_Decision`
- **Page portfolio** : `/projets/objectively`

**Résumé** : Plateforme SaaS française d'évaluation collaborative multi-critères. Remplace Excel dans les processus de décision où plusieurs personnes évaluent plusieurs options selon des critères pondérés.

**Tagline** : "Arrêtez de perdre du temps sur Excel pour vos évaluations fournisseurs, candidats ou projets"

**Stack** :
- Next.js, TypeScript, Tailwind CSS
- Supabase (PostgreSQL + Auth + RLS)
- Stripe (abonnements + webhooks)
- Hébergement : Vercel

**Modèles tarifaires** :
- **Gratuit** : Découverte / usage ponctuel
- **Pro** : 29€/mois — acheteurs individuels, consultants, managers RH
- **Team** : 69€/mois — services achats, équipes RH
- **Business** : Sur devis — centrales d'achats, grandes entreprises (marque blanche, support VIP)

**Deux modes d'évaluation** :

| Dimension | Auto-évaluation | Évaluation-multiple |
|---|---|---|
| Principe | 1 évaluation par option (le sujet remplit lui-même) | N évaluateurs (pondérés) évaluent toutes les options |
| Interface formulaire | Verticale, 1 option à la fois | Tableau : lignes = critères, colonnes = options |
| Lien de complétion | Par option (`?option=`) | Par évaluateur (`/evaluator/[id]`) |
| Synthèse | Colonnes = options | Colonnes = options × évaluateurs + Score Final |
| Idéal pour | Collecte auprès des sujets (candidats, fournisseurs) | Décision collégiale par un comité |

**Architecture workspace** :
- Multi-tenancy avec RLS Supabase
- Rôles : administrateur / membre
- Invitations par email (lien valide 72h)
- Thèmes par workspace (5 thèmes prédéfinis + personnalisation complète des tokens CSS)

**Fonctionnalités clés** :
- Grilles de critères hiérarchiques avec pondération (doit totaliser 100% à chaque niveau)
- 4 types de notation : Note, Nombre en %, Nombre en unité (calcul linéaire/affine/formule), Oui/Non
- Évaluateurs externes sans compte (via lien public)
- Exports : Grille PDF, Rapport PDF, CSV
- Bibliothèque de critères et de consultations (modèles réutilisables au niveau workspace)
- Drag-and-drop pour réorganiser les critères
- Blog SEO (8 articles + 4 pages verticales : /achats, /recrutement, /audits, /investissements)
